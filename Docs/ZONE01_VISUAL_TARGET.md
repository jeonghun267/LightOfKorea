# 수정된 시각적 목표 — 2026-09-07

사용자가 제공한 두 번째 이미지가 시각적 목표다. 기존 테스트 렌더는 기능 검증용 초안이며 목표 품질을 달성한 결과로 보지 않는다.

- 중앙: 거대한 백색·청색 달항아리, 몸체의 은은한 문양과 달빛.
- 좌우: 가지가 있는 발광 나무, 청록·보라색 수관, 수직으로 내려오는 빛.
- 우측 중경: 전통 한옥 정자와 따뜻한 기둥 조명.
- 중앙 원근: 낮은 계단·담장, 먼 산/암석의 어두운 실루엣.
- 바닥: 젖은 거울 같은 반사, 원형 빛 파동, 따뜻한 낮은 등불.
- 낮은 안개와 입자로 공간의 깊이를 만들되 하얗게 뭉치지 않게 한다.

먼저 기본 오브젝트로 배치·색·깊이를 맞춘 뒤 실제 Unreal 렌더와 비교한다. 참조 이미지를 배경판으로 붙여 구현 결과처럼 제시하지 않는다.

사용자 첫 스크린샷은 `Main` 맵이다. 생성 장면은 `Content/LOK/Maps/Zone01/LV_Zone01_Moonlight.umap`에 별도로 저장되어 있다. 기존 시작 맵과 Ray Tracing/Lumen/nDisplay 설정은 유지한다. 현재 Editor의 원격 콘솔 실행은 설정상 비활성으로 확인됐으며 변경하지 않았다.
